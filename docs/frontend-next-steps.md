## 2) Opacity/레이어 정책 기준표

목표: "가독성 우선 + 지도 정보 가림 최소화"

### 상단/패널
- 상단 검색 컨트롤: 기본 `bg-white/90` ~ `bg-white/94`
- 조건 드로어: 기본 `bg-white/92`
- 사이드바 배경: `bg-slate-950/88` 수준 유지
- 모바일 오버레이 딤: `bg-slate-950/32` ~ `0.40`

### 3D 장면 레이어
- 동 경계 라인: 시인성 우선 (`0.65` 이상)
- 동 경계 글로우: 과도한 번짐 방지 (`0.10` ~ `0.20`)
- 도로 외 배경(non-road): 정보 가림 방지 (`0.02` ~ `0.08`)

### 상호작용 시
- 포커스 모드 진입 시 상단/하단 UI의 opacity를 추가로 낮추거나 자동 숨김
- 패널 열림 상태에서 지도 조작 힌트/레이블 opacity 하향

## 3) 실시간 교통 레이어 API 계약 초안

아래 스키마는 "Tmap 스타일 도로 혼잡 색상" 표시를 위한 최소 계약이다.

### 3.1 Endpoint
- `GET /api/traffic-links`

### 3.2 Query params
- `bbox`: `minLon,minLat,maxLon,maxLat` (현재 뷰포트)
- `at`: ISO datetime (옵션, 서버 미지정 시 latest)
- `level`: `road|dong` (기본 `road`)

예시:
```
GET /api/traffic-links?bbox=127.018,37.492,127.052,37.516&level=road
```

### 3.3 Response (road)
```json
{
  "as_of": "2026-05-20T06:20:00Z",
  "ttl_sec": 60,
  "units": {
    "speed": "kmh",
    "volume": "vph"
  },
  "links": [
    {
      "link_id": "1220034501",
      "speed": 21.4,
      "volume_vph": 1280,
      "congestion_level": "heavy",
      "source": "seoul_openapi"
    }
  ]
}
```

### 3.4 Response (dong aggregate)
```json
{
  "as_of": "2026-05-20T06:20:00Z",
  "ttl_sec": 120,
  "dongs": [
    {
      "dong": "역삼1동",
      "avg_speed": 24.8,
      "congestion_score": 0.72,
      "sampled_links": 83
    }
  ]
}
```

### 3.5 색상 매핑 권장값
- `free` (원활): `#22c55e`
- `slow` (서행): `#f59e0b`
- `heavy` (정체): `#ef4444`
- `unknown`: `#64748b`

### 3.6 프런트 반영 우선순위
1. `link_id -> segment` 매핑 구축
2. 폴리라인 material 색상 갱신 함수 추가
3. `교통 레이어` 토글(ON/OFF)
4. legend/마지막 갱신 시각(`as_of`) 표시
